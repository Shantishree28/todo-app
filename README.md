# 📝 To-Do List App (JavaScript DOM + LocalStorage)

A fully functional **task management application** built using vanilla JavaScript.

---

## 🚀 Features

- ✅ Add tasks (Create)
- 📖 View tasks (Read)
- ✏️ Mark tasks as completed (Update)
- ❌ Delete tasks (Delete)
- 💾 Persistent storage using localStorage
- 🔍 Filter tasks (All / Active / Completed)
- ⚡ Dynamic DOM manipulation
- 🎯 Event delegation & handling

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Browser LocalStorage
